# Референсные материалы Shveyka

Эта папка хранит материалы которые не являются исполняемым кодом,
но используются при планировании новых фич и UI-текстов.

## Ожидаемые файлы (пользователь положит вручную)

- `ux-copy.pdf` — готовые UX-тексты на русском (главная, онбординг,
  подсказки к меркам, empty states, ошибки, кнопки).
  **Источник для всех пользовательских строк UI** —
  использовать при добавлении любых новых экранов.
- `ux-copy.html` — HTML-версия тех же текстов (удобно открывать в браузере).
- `alt-architecture.md` — альтернативная архитектура "sewing-cabinet"
  от предыдущего ресерча. НЕ применять напрямую (другой namespace
  @sewing, другие драйверы), но полезно как источник идей для
  AI-чата и расширенной схемы БД.
- `alt-schema-api.md` — расширенная SQL-схема и список REST API
  эндпоинтов из того же ресерча. Использовать как подсказку при
  проектировании таблиц `conversations`, `messages`, `measurements`
  для будущих блоков.

## Принцип

Когда AI-помощник (Kimi / Cline) работает над новой фичей и ему
нужны UI-тексты, тон, или идеи по структуре БД — он должен
сначала проверить docs/ на предмет готовых материалов, и только
потом писать своё.
