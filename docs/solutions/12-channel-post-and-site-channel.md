# 12 — Пост в канал с кнопками и канал на сайте

## Задача

Бот сам пишет в канал мастерской: короткий текст и кнопки под ним. На сайте
появилась ссылка на канал — рядом с ботом, но отдельной кнопкой, чтобы их не
перепутать.

## Что сделано

### Бот (`apps/bot`)

- `src/lib/channel.ts` — чистая часть: текст поста, кнопки, экранирование HTML
  и проверка прав на публикацию. Ни сети, ни Telegram — поэтому тестируется
  обычным тестом.
- `src/channel.ts` — публикация: `publishChannelPost(bot, options)` отправляет
  пост в канал через `bot.api.sendMessage` и превращает ошибки Telegram в
  понятные владельцу слова («назначь бота администратором канала»).
- `src/bot.ts` — команда `/post` (только владелец) публикует заготовленный
  пост; со своим текстом — `/post Текст поста`. Команда не попадает в меню
  Telegram (`BOT_COMMANDS`), чтобы не мозолить глаза обычным пользователям.
- `src/scripts/postToChannel.ts` — публикация из командной строки, когда бот не
  запущен: `pnpm bot:post` или `pnpm bot:post "Текст поста"`.
- `/start` теперь понимает полезную нагрузку: ссылка `t.me/бот?start=cut`
  открывает нужный сценарий сразу.

### Сайт (`apps/web`)

- `src/lib/site.ts` — `TELEGRAM_CHANNEL_URL` и `TELEGRAM_CHANNEL_TITLE`
  (задаются `NEXT_PUBLIC_TELEGRAM_CHANNEL_URL` и `NEXT_PUBLIC_TELEGRAM_CHANNEL_TITLE`).
- `src/components/TelegramChannelButton.tsx` — кнопка «Открыть канал» со знаком
  рупора (у Telegram — самолётик). Два варианта: `solid` и `quiet`.
- Канал добавлен в подвал, на главную и на страницу помощника — везде рядом с
  кнопкой бота, в одной строке.

## Кнопки в посте

По две в ряд, внизу одна широкая на сайт:

```
🧵 Раскрой ткани    💰 Выгодно ли шить?
🔍 Аналог ткани      🧷 Фурнитура
🧼 Уход за тканью    🤖 Спросить бота
🌐 Открыть сайт
```

Первые шесть кнопок ведут на страницы сайта, «Спросить бота» открывает чат с
ботом (`?start=ask`), последняя — на сайт целиком. Ровно столько кнопок,
сколько нужно: ряд «на всякий случай» читается как натыканная панель.

## Переменные окружения

```bash
# apps/bot/.env
CHANNEL_ID=@shveyka_igolka       # чат канала: @username или -100…
CHANNEL_URL=https://t.me/shveyka_igolka
OWNER_USER_IDS=                  # кому можно /post; пусто — берётся ALLOWED_USER_IDS

# корень .env или apps/web/.env.local
NEXT_PUBLIC_TELEGRAM_CHANNEL_URL=https://t.me/shveyka_igolka
NEXT_PUBLIC_TELEGRAM_CHANNEL_TITLE=Швейка · мастерская
```

## Что нужно на стороне Telegram

Бот должен быть администратором канала с правом публикации сообщений. Без
этого Telegram отвечает 403, и бот объясняет это одной фразой.

## Проверка

```bash
pnpm typecheck && pnpm lint && pnpm test && pnpm build
```

Тесты бота: `apps/bot/src/channel.test.ts` — текст поста, раскладка кнопок,
экранирование своего текста, отказ без канала и без прав, проверка списка
владельцев.
