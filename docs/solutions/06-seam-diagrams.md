# 06. Схемы швов без фотостудии

**Проблема (D6/B8).** `diagram_url` пуст у всех 16 швов.

## Решение

`core/diagrams/seamSvg.ts` генерирует SVG из типа шва: `plain`, `zigzag`, `overlock`, `french`, `flatFelled`, `hem`, `blind`, `topstitch`. Тип определяется по `id`/`slug`/названию (`classifySeam`, порядок правил важен: «потайной подгиб» → `blind`, а не `hem`); неизвестный шов получает схему стачного.

- Ткань рисуется `currentColor` — схема сама подстраивается под светлую и тёмную тему; нить — акцентный `#c2410c`.
- Ноль зависимостей и сетевых запросов, вес ≈ 1 КБ на схему.
- `aria-label` экранируется — единственное место, куда попадает внешний текст.
- Классы схемы с префиксом `shv-`: короткое имя класса легко пересекается с чужим и стили схемы задели бы другие элементы страницы.
- Компонент `SeamDiagram` показывает `diagram_url`, если он заполнен; иначе — сгенерированную схему. Появится реальное фото — оно автоматически главнее.

```tsx
<SeamDiagram id={seam.id} slug={seam.slug} name={seam.name} diagramUrl={seam.diagram_url} />
```

## Допущение

Правила `classifySeam` рассчитаны на типовые русские и английские названия. Если у какого-то из 16 швов схема не совпала с ожиданием — добавьте регулярку в `RULES` (одна строка), тест на классификацию уже есть.

К правилам из плана добавлены «выворот» (двойной выворотной шов), «бейк» и
«обтач»: без них часть швов каталога получала бы общую схему стачного шва.
Тест перечисляет все 16 швов каталога — если в сидах появится новый шов,
тест подскажет, что схема для него не подобрана.

Схемы — **схематичные сечения**, а не чертёж с размерами: размеры припусков остаются в тексте шва.
