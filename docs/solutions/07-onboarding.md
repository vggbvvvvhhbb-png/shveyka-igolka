# 07. Стартовый экран «С чего начать»

**Закрывает:** B6.

Страница `/start` — обычная GET-форма из трёх вопросов, **без клиентского JS**: результат считается на сервере и открывается по ссылке, которой можно поделиться (`/start?garment=…&fabric=…&own=1`).

`core/onboarding/recommend.ts` → `recommendStart(graph, answers)`:

- **проект**: подходящий изделию; если выбрана ткань, то сначала тот, что с ней связан;
- **ткани** (до двух): выбранная + рекомендованные проектом;
- **шов**: первый из `required_seams` проекта, иначе первый шов ткани;
- неизвестное изделие даёт «ничего не нашлось», а не случайный проект;
- ответ «шью не на Brother LS-200s» добавляет честную заметку: настройки каталога — для этой модели.

Подписи типов изделий берутся из названия первого проекта этого типа — словарь из 10 `garment_type` не нужен.

## Подключение

Добавить пункт «С чего начать» в `Header`, а на главной — ссылку-кнопку на `/start`. Страница уже в sitemap (`STATIC_PAGES`).
